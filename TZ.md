**Версия:** 1.0 · 12.10.2026
**Этап:** подготовка. Верстка идёт отдельно, в терминале (Claude Code).
**Читать вместе с:** [`DESIGN.md`](DESIGN.md) (дизайн-система) · [`content/content.json`](content/content.json) (весь контент) · [`CHECKLIST.md`](CHECKLIST.md) (покрытие видео и дат)

---

## 1. Цель

Одностраничный сайт-презентация DJ NAGOO заменяет PDF-промокит, который раньше собирали в Photoshop. Ссылка уходит букинг-агентствам и промоутерам.

**Задача сайта за 60 секунд просмотра:**
1. С первого экрана: «это артист уровня, его привозят» (вау-эффект).
2. Дать доказательства: 20+ лет, резидентства, награда, 16 дат на 4 рынках, живое видео.
3. Привести к контакту для букинга в один клик из любой точки страницы.

**Аудитория:** букинг-агенты и промоутеры. Насмотренные, смотрят быстро, часто с телефона (ссылка из WhatsApp/Telegram/почты). Язык сайта — **английский** (рынки: Бахрейн, Египет, Оман, Россия).

**Тон:** ультрасовременный, модный, много анимации, но не в ущерб скорости.

## 2. Стек

| Слой | Решение | Зачем |
|---|---|---|
| Сборка | **Vite + React 18 + TypeScript** | Компоненты 21st.dev написаны на React + Tailwind. SSR не нужен: сайт статический |
| Стили | **Tailwind CSS v4** + CSS-переменные из `DESIGN.md §2` | Компоненты 21st ожидают shadcn-токены (`bg-background`, `text-foreground`). Их маппим на наши: `--background: var(--ink)`, `--foreground: var(--bone)`, `--muted-foreground: var(--bone-dim)` |
| Анимация | **motion** (бывш. framer-motion) + **GSAP ScrollTrigger** + **Lenis** | motion — для компонентов и hover, GSAP — для scrub/pin-сцен, Lenis — плавный скролл |
| WebGL | Сырой WebGL2 (как в velvet-haze), без three.js | Вес |
| Видео-компоненты 21st (Remotion) | **@remotion/player** или нативная переделка (см. §5) | `bar-built-digits` и `polyrhythm-orbit-list` — это Remotion-композиции, а не DOM-компоненты |
| Шрифты | Archivo (variable, оси wght+wdth) + JetBrains Mono, **self-host** woff2, subset Latin | Без Google Fonts CDN: быстрее первый экран |
| Хостинг | Vercel (или GitHub Pages) | Статический билд, превью на каждый пуш |
| Контент | `content/content.json` | Никакого хардкода текста в компонентах |

## 4. Структура страницы

Порядок и ритм — по `DESIGN.md §5.2`. Нумерация секций выводится в рамке видоискателя (`03 / 09`).

### 00 · Preloader (≤ 1.6s, только при первом визите в сессии)
- Фон `--ink`. По центру счётчик `0 → 100`, цифры собираются из вертикальных баров (концепт 21st `bar-built-digits`, переписанный на DOM/motion, без Remotion).
- На 100 бары разъезжаются вертикальными шторками, под ними уже Hero. Шторки закатного цвета: crimson → ember по очереди.
- Реальная загрузка: шрифты + `hero-main.webp` + cutout. Счётчик не врёт: привязан к промисам.

### 01 · Hero
**Контент:** `hero.main`, `hero.cutout`, `artist.wordmark`, `artist.role`, `artist.since`, `artist.tagline`.

**Композиция (desktop):**
- Слой 1: фото `hero-main.webp` full-bleed (градиент crimson→ember уже на фото).
- Слой 2: вордмарк `DJNAGOO` (`--t-mega`, `--ink` с opacity .9 либо `--bone`). Стоит **за головой артиста**: перекрывает фон, но не человека.
- Слой 3: `hero-main-cutout.webp` — артист без фона (см. TODO-1).
- Микро-лейблы (SEKO): слева сверху `DJ & PRODUCER / SINCE 2005 / BAHRAIN`, справа по центру `WHEN MUSIC CAN TEMPT U.`, справа у края декор-штрихкод.
- Слева снизу: `SCROLL ↓` в mono.

**Анимация:**
- Вход после прелоадера: вордмарк появляется морфингом ширины `wdth 62 → 125` (буквы «раздвигаются»), фото чуть отъезжает `scale 1.08 → 1`.
- Mouse-parallax: фон ±8px, вордмарк ±16px, артист ±4px → объём.
- Scroll-scrub (pin 100vh): вордмарк растёт ×1.4 и уходит вверх, градиент темнеет в `--ink`, артист уезжает медленнее (parallax). Переход в Manifest.

**Mobile:** `hero-vertical.webp` (9:16), вордмарк внизу кадра на всю ширину (как в исходнике `nagoo.jpg`), без cutout-слоя.

### 02 · Manifest (светлая пауза, `--bone` фон)
**Контент:** `bio.short`, `artist.highlights` (награды только в списке, абзац без них).
- Заголовок в 3 строки, начинается с 5-й колонки (SEKO): `BEHIND THE DECKS` (ink) / `FOR TWENTY` (ink) / `YEARS.` (ink 30%), точка `--ember`.
- Справа внизу (колонки 9–12): `bio.short` + 4 highlights списком в mono.
- Слева: крупное вертикальное ч/б фото `press-03-throne` в колонках 1–4, по высоте от верха заголовка до низа блока (~80svh), скругление 20px, вход маской снизу вверх + параллакс (кадр едет медленнее текста). На mobile — на всю ширину 4:5 между заголовком и текстом. (Было: `press-02` 240px; решение пересмотрено на ревью.)
- Анимация: строки заголовка line-mask, «бледная» строка дозаливается в полный цвет по мере скролла (scrub).

### 03 · Stats (секция-удар, градиентная полоса)
**Контент:** `stats[]` (годы стажа считать: `currentYear − 2005`).
- Полоса на 100vw, фон `--grad-sunset`, высота ~70vh.
- 4–5 цифр в ряд (`--t-lg`/`--t-xl`, `--ink`), под каждой mono-подпись (addco: `90%` + `■ SUCCESS RATE`).
- Анимация: цифры собираются из баров (тот же компонент, что в прелоадере), stagger 120ms, срабатывает 1 раз при входе.

### 04 · Sound (жанры)
**Контент:** `genres[]` (8 шт.).
- Заголовок `THE SOUND.`
- Центральная сцена — **polyrhythm orbits**: 3 концентрические орбиты, жанры-pill крутятся с разной скоростью (полиритм 3:4:5). В центре вращающаяся виниловая пластинка с фото артиста на этикетке (`press-04`, оригинальный цвет), скретч мышью/пальцем.
  - Реализация: переписать идею 21st `polyrhythm-orbit-list` на DOM + motion (`rotate` контейнеров орбит, контр-вращение pill-ов, чтобы текст оставался горизонтальным). Remotion здесь не нужен: в DOM интерактивнее.
- Hover по жанру: орбита замедляется, pill заливается `--ember`.
- Mobile: орбиты сохраняются в масштабе 0.6; под ними дублирующий список жанров (доступность).

### 05 · Video
**Контент:** `videos[]` — **все 3 ролика обязательны**.
- Заголовок `LIVE.`
- Три вертикальных 9:16 «экрана» в ряд без рамок, скругление 20px, разной высоты (центральный выше и выдвинут вперёд — v01 главный).
- Порядок: `v03` (атмосфера, ч/б) · **`v01`** (главный, крупный) · `v02` (толпа, **не шире 360px**, под зерном).
- Автоплей muted loop для видимых. Hover/тап → звук включается на этом ролике, остальные глохнут. Курсор → `SOUND ON`.
- Клик → fullscreen-лайтбокс с плеером.
- Scroll: ролики въезжают снизу с разной скоростью (parallax 0.9 / 1 / 1.1) и слегка поворачиваются ±3° → выпрямляются.
- `preload="none"` для невидимых, `poster` из `video-0X-poster.jpg`.

### 06 · Timeline (карьера)
**Контент:** `timeline[]` (8 этапов).
- Заголовок `THE PATH.`
- Горизонтальный скролл в pin-секции (desktop): лента этапов `2005 → NOW`. Каждый этап: год-диапазон (mono), роль (`--t-md` сжатый), площадка + страна (dim).
- Сквозь ленту идёт **gradient tracing** линия (21st `gradient-tracing`, перекрашена в `--grad-sunset`), «бегущий» градиент движется по скроллу. На наградах (2018) линия делает петлю и стоит точка `--ember` + метка `AWARD`.
- Mobile: вертикальная лента, линия слева.

### 07 · Tour (архив дат)
**Контент:** `tour.items[]` — **все 16 дат обязательны**, `venues[]`.
- Заголовок `ON THE ROAD.` + mono-счётчик `16 NIGHTS · 5 CITIES · 2022—2023`.
- **Вид A — Список** (по умолчанию): строки по `DESIGN.md §6` «Строка тура», хронология сверху вниз (или новые сверху — решить на критике). Hover: заливка градиентом + всплывающая афиша рядом с курсором, наклон по направлению движения мыши.
- **Вид B — Папки** (переключатель `LIST / CITIES` в mono): 21st **`glass-folder-cards`** (`tone="dark"`), 5 папок по городам: `Manama/Bahrain (8)`, `Saint Petersburg (1)`, `Sevastopol (1)`, `Hurghada (4)`, `Muscat (2)`. Клик открывает папку → афиши этого города веером, клик по афише → лайтбокс.
  - Перекрасить встроенные арты (`aurora/ember/dusk`) под палитру: только ember/crimson/ink.
- Даты без точного дня (`date: null`) выводить как `FEB 2023`, без выдуманного числа.
- Под списком — **marquee площадок** (`venues[]`), Archivo сжатый `--t-lg`, бледный, разделитель `●` в `--ember`. Скорость реагирует на velocity скролла.

### 08 · Gallery
**Контент:** все 6 `press[]` + 16 афиш + 3 постера видео (чередовать).
- 21st **`tilted-grid-hero`** (обязательно, «галерею точно отсюда»): изогнутая бесконечная лента изображений, края загибаются к зрителю и гаснут, центр плоский.
- Поверх, по центру: `ON & OFF STAGE.` (`--t-xl`) + mono-подпись.
- Фото в ленте — в оригинальном цвете; края ленты приглушены виньеткой, центр ярче.
- Клик по кадру → лайтбокс-слайдер (свайп на мобиле).

### 09 · Booking + Footer
**Контент:** `contacts`.
- Фон: 21st **`velvet-haze`** (WebGL), перекрашенный: серебро → `--ember`, фиолет → `--crimson`, база `--ink`. Дымка собирается под курсором, клик = рябь.
- По центру: `BOOK NAGOO.` (`--t-xl`) + огромная круглая CTA (160px) `WRITE` → `mailto:`.
- Под ней — 3 строки контактов `--t-md`: телефон (tel:) · WhatsApp · email. Каждая с copy-to-clipboard по клику и тостом `COPIED` в mono.
- Соцссылки: Instagram · Facebook · SoundCloud (mono, magnetic).
- Кнопка `DOWNLOAD PRESS KIT (PDF)` — появится после этапа PDF (§8). До этого скрыта.
- **Футер:** одна тонкая mono-строка внизу секции Booking: `© 2026 DJ NAGOO · PRESS KIT` слева, `BACK TO TOP ↑` справа; дымка плавно уходит в ink к низу страницы (полутоновой вордмарк убран по ревью).

## 7. Нефункциональные требования

- **Скорость:** LCP < 2.5s на 4G, первый экран < 600KB (без видео). Видео и шейдеры грузятся лениво. Lighthouse Performance ≥ 85 mobile, ≥ 95 desktop.
- **Анимация:** 60fps, только transform/opacity/filter/font-variation. Проверить на среднем Android.
- **Reduced motion:** см. `DESIGN.md §7`.
- **Доступность:** контраст по `DESIGN.md §2.3`, все медиа с alt, видео с кнопкой паузы, навигация с клавиатуры, `:focus-visible` = кольцо 2px `--ember`.
- **SEO/шеринг:** title `DJ NAGOO — Press Kit`, description из `bio.short`, OG/Twitter-карточки (превью в WhatsApp/Telegram критично: так ссылку и отправляют), favicon из «N» логотипа.
- **Браузеры:** последние Chrome, Safari (iOS ≥ 16: проверить WebGL2 и автоплей), Firefox, Samsung Internet.
- **Без трекеров**, кроме опционально Vercel Analytics (кто открывал кит — полезно для букинга).

- Порядок слайдов: Hero · Manifest · Stats · Sound · Video (постеры + QR) · Path · Tour (2 слайда: список + сетка 16 афиш) · Gallery (коллаж) · Booking.
